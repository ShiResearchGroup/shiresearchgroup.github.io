Mofography

Structural analysis and visualization for nanoporous materials

Web app available

Mofography is a powerful Python package for the structural analysis and visualization of nanoporous materials like MOFs, zeolites, and activated carbons.

  • Python
  • Rust backend
  • MOFs
  • Zeolites
  • Activated carbons
  • Visualization
  • Structural analysis
